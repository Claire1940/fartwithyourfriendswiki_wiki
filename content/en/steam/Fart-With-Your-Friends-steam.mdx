<Section icon={Users} title="Multiplayer Preparation and Party Tips">

A good party session depends on clear communication and a simple plan. Decide who will host, confirm that everyone has installed the same current build, and agree on voice communication before sending invitations.

Use the host with the most stable connection when possible. If the game offers room codes, invite tools, or lobby settings, share only the information your group needs and keep the session private when available.

<Callout type="info" title="Group Planning">
Choose one host, one backup host, and one voice channel. This makes it easier to recover if the first lobby disconnects or a player needs to rejoin.
</Callout>

| Role | Responsibility | Useful habit |
| --- | --- | --- |
| Host | Creates and manages the session | Test the lobby before inviting everyone |
| Players | Join the correct room and check controls | Avoid changing settings during a live round |
| Voice lead | Explains the next objective | Keep instructions short and specific |
| Backup host | Restarts the session if needed | Know how to invite the group again |

For a smoother start:

- Invite players after the host reaches the main lobby.
- Ask everyone to confirm that their microphone and output device work.
- Keep background downloads paused during the first session.
- Use a consistent nickname so the host can identify each participant.
- Restart the lobby if several players experience the same connection problem.

<Section icon={ShieldCheck} title="Troubleshooting Fart With Your Friends on Steam">

When Fart With Your Friends does not launch or connect properly, troubleshoot one variable at a time. Start with Steam and the game installation, then check local devices and network settings. Avoid changing several settings at once because it makes the cause harder to identify.

<Callout type="warning" title="Troubleshooting Order">
First restart the game and Steam, then verify the installation, then check audio and network settings. If the issue affects every player, compare the current Steam news or support information.
</Callout>

| Symptom | First action | Next action |
| --- | --- | --- |
| Game will not launch | Restart Steam | Verify the installed files |
| Black or incorrect display | Change display mode | Update graphics drivers if needed |
| No game audio | Check output device | Review system volume and in-game audio |
| Microphone unavailable | Select the correct input | Test the microphone outside the game |
| Friends cannot join | Recreate the lobby | Have another player test as host |
| Disconnects continue | Pause downloads | Test a more stable network connection |
