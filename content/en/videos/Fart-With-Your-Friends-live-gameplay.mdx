<Section icon={Users} title="Live Multiplayer Setup and Team Coordination">

Playing with friends is most effective when everyone joins the same Roblox experience before selecting a challenge. For competitive sessions, organize the teams first and confirm that each player knows the intended format.

Raft Race supports 1v1, 2v2, 3v3, and 4v4 arrangements. Balanced team sizes make the match easier to read and reduce confusion during the opening movement. In cooperative activities, the same communication principles still apply: one clear instruction is usually easier to follow than several simultaneous commands.

| Setup Stage | Team Action | Common Problem | Better Solution |
|---|---|---|---|
| Before joining | Confirm which friends are participating | A player enters late | Set the roster before choosing a mode |
| Server entry | Make sure everyone reaches the same experience | Players load into separate sessions | Verify the shared session before starting |
| Team formation | Select equal teams when possible | Uneven competitive groups | Use matching team sizes |
| Command plan | Choose a caller for major turns | Multiple conflicting directions | Use short, agreed callouts |
| After the run | Review the hardest section | The same mistake repeats | Discuss one improvement before retrying |

<Section icon={Shield} title="Raft Control, Obstacles, and Recovery Tips">

The safest live gameplay habit is to look ahead before changing direction. Sudden repeated inputs can make a difficult section harder, especially when several players react to the same obstacle in different ways.

Use short callouts such as “left,” “right,” “slow,” or “turn.” The exact control response depends on the available in-game movement system, so new players should test the raft during an early section instead of assuming that large movements are always better.

| Situation | Risk | Recommended Response |
|---|---|---|
| Approaching a turn | Turning too late | Call the direction early and make a controlled adjustment |
| Narrow route | Overcorrecting | Use smaller movement changes |
| Multiple hazards | Players react separately | Follow the caller and prioritize the next immediate threat |
| Group disagreement | Conflicting inputs | Pause verbal instructions and select one direction |
| Failed section | Repeating the same mistake | Identify the trigger, then simplify the next attempt |
